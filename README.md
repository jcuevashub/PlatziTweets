# PlatziTweets

**PlatziTweets** is an iOS app built with **UIKit** that allows users to view, post, and interact with tweets in real-time. It provides a sleek and responsive interface for users to manage their Twitter feed and share content with friends.

## Features

- **View Tweets**: Browse a timeline of tweets from users you follow.
- **Post Tweets**: Write and publish new tweets directly from the app.
- **Like/Retweet**: Interact with tweets by liking or retweeting them.
- **Profile**: View and edit your Twitter profile.
- **Search**: Search for specific tweets, users, or hashtags.
- **Push Notifications**: Get notified when you have new interactions or mentions.
- **Dark/Light Mode**: Automatically switches between dark and light modes depending on system preferences.

## Tech Stack

- **Swift**: Programming language used for iOS development.
- **UIKit**: Framework used for building the user interface in an imperative style.
- **CoreData**: Used for managing persistent data and caching tweets locally.
- **Alamofire**: Library for making network requests to the Twitter API.
- **JSONDecoder**: Used to decode JSON responses from the Twitter API.
- **Push Notifications**: Integrated for real-time notifications about mentions and interactions.
